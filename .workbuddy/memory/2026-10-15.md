## PixelForge 图片工具站（新项目）
- 需求：图片压缩 / 格式转换 / 裁剪 / 编辑的网站。
- 方案：纯前端单文件 `index.html`（CSS/JS 全内联，零依赖零构建），Canvas API 全本地处理，图片不上传。双击即用，可直接部署任意静态托管。
- 功能：批量压缩（质量滑块 + 目标体积二分搜索 + 最大宽高）、格式转换（JPEG/PNG/WebP/AVIF 自动探测 + 透明填充色）、裁剪（8 手柄拖拽 + 比例锁定 + 旋转/翻转）、美化（亮度/对比度/饱和度/色相/模糊/锐化卷积/灰度/复古/反色 + 10 预设 + 圆角 + 文字水印）、批量处理、明暗主题、移动端响应式、拖拽/粘贴导入、快捷键 1-4 切工具 + Ctrl+S 导出。
- 架构要点：旋转/翻转/裁剪 per-file 存储（tf 对象），滤镜/水印全局共享；裁剪框实时 commit（切工具不丢）；导出管线 = 旋转翻转→裁剪→滤镜→圆角→水印→锐化→缩放→编码。
- 踩坑修复：file:// 下 localStorage 需 try/catch（SecurityError 会挂掉整个初始化）；重复导出同名文件会被 Chrome 静默覆盖 → 会话内 uniqueName 去重；滑块 step 吸附导致目标体积无法精确 → 加数字输入框联动。
- 验证：puppeteer-core + 本机 Chrome 冒烟测试 32/32 通过（含 WebP/JPEG 文件头校验、8KB 目标命中、批量下载计数、裁剪拖拽、响应式无横向溢出），无控制台错误。测试脚本已清理。
