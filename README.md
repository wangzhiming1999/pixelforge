# PixelForge · 图片工坊

纯浏览器端的图片处理工具：**压缩 / 格式转换 / 裁剪 / 美化**，单文件、零依赖、零构建，图片永不离开你的电脑。

[在线使用](#部署) · [功能一览](#功能一览) · [快速开始](#快速开始) · [部署](#部署) · [技术实现](#技术实现) · [License](#license)

---

## 为什么是 PixelForge

- **隐私优先** — 全部处理在本地浏览器完成，无上传、无埋点、无追踪
- **单文件** — 一个 `index.html` 搞定一切，没有 node_modules，没有构建步骤
- **零成本部署** — 任意静态托管直接扔，双击本地文件也能用
- **批量处理** — 多文件队列 + 一键按当前设置处理全部

## 功能一览

### 🗜 压缩
- 质量滑块精细控制（JPEG / WebP / AVIF）
- **目标体积模式**：输入精确的目标 KB，二分搜索自动寻找最优质量（如"压到 100KB 以内"）
- 最大宽 / 高限制，按比例缩放不失真
- PNG 自动识别为无损，禁用无效控件

### 🔄 格式转换
- JPEG / PNG / WebP / AVIF 互转，启动时自动探测浏览器编码能力
- 透明通道填充色可选（JPEG 不支持透明）
- 智能默认：转 JPEG 时才填充，其余保留透明

### ✂️ 裁剪
- 8 向手柄自由拖拽，实时显示像素尺寸
- 比例锁定：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16
- 90° 旋转、水平 / 垂直翻转
- 裁剪状态实时生效，切换工具后保留（按文件独立存储）

### 🎨 美化
- 基础调整：亮度 / 对比度 / 饱和度 / 色相 / 模糊 / 锐化（导出时卷积计算）
- 风格滤镜：黑白 / 复古棕褐 / 反色 + 10 个一键预设（通透、暖阳、胶片、暗调…）
- 圆角、文字水印（6 个位置、字号 / 颜色 / 不透明度可调）
- 所有调整实时预览

### 📦 通用
- 拖拽 / 点击 / `Ctrl+V` 粘贴三种导入方式，支持批量
- 批量处理：按当前工具设置处理文件列表全部图片
- 明暗主题（跟随记忆）、移动端响应式布局
- 快捷键：`1-4` 切换工具，`Ctrl+S` 导出当前图片
- 导出文件名自动去重，不会覆盖旧文件

## 快速开始

无需安装任何东西：

```bash
# 方式一：直接下载
# 下载 index.html，双击打开即可

# 方式二：克隆仓库
git clone https://github.com/wangzhiming1999/pixelforge.git
# 然后直接双击打开 index.html（file:// 协议下完整可用）
```

> 提示：也可以起一个静态服务器 `npx serve .`，效果一致。

| Nginx / 自己的服务器 | 把 `index.html` 放进站点目录 |

## 技术实现

- **零依赖**：原生 Canvas 2D API + `createImageBitmap` + Blob 下载，无任何第三方库
- **格式探测**：启动时用 `canvas.toBlob` 探测 WebP / AVIF 编码支持，不支持的选项自动禁用
- **目标体积压缩**：对编码质量做二分搜索（8 轮迭代），收敛到最接近目标体积的质量值
- **锐化**：导出时对 ImageData 做 3×3 卷积（unsharp mask），预览阶段跳过以保证滑块流畅
- **滤镜管线**：预览用 `ctx.filter`（CSS filter 语法）实时渲染；导出时按「旋转翻转 → 裁剪 → 滤镜 → 圆角 → 水印 → 锐化 → 缩放 → 编码」顺序合成
- **状态设计**：旋转 / 翻转 / 裁剪按文件独立存储，滤镜 / 水印全局共享
- **降级策略**：`createImageBitmap` 失败时回退 `Image` 元素解码；`file://` 协议下 localStorage 异常做了防御
